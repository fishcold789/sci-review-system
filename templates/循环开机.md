## ① 基准文件骨架 → `<节号>_母本基准.md`

```
> 本文件是循环对标的唯一基准。每轮改完与它逐段比对。
> 计词口径：<正则；剥不剥引文括号——写死，比对两边必须同一口径>

逐段实测表：段号｜词数｜句数｜句长序列｜段内σ｜这段在干什么
全节指标：总词数｜段均｜句均｜从属密度｜句首类型分布（最大类 %）｜
          引文位密度（每千词）｜页码级引用数｜段长 max/min
写法可借用清单：母本自己用过的连接词与句式——补差时只从这里取，不发明
```

## ② 约束文件骨架 → `<节号>_约束.md`

```
〇 总则：指标给方向，不为刷分；指标不达标而文字好，优于指标达标而文字坏
一 三病与判据：温吞（无法被具体事实证伪）／泛泛的确凿（删掉确定性词看剩什么）／
   替读者补课（删掉后论证链不缺环就删）
二 违禁词：通用表＋本项目实际犯过的另列一栏（后者优先级更高）
三 结构反模式：二元对比句全节至多一处且必须是那句判词／换句式重述（不带新信息只带
   语气，删）／无源引用／句长均匀／破折号
四 正向条款：具体动作优先；落到工程上怎么判；允许普通句子；适度重复可承担转场
五 呼吸感：长段后必跟短段；末段最短；四句以上段内σ ≥ 基准实测下限
六 逐段实录区：段号｜人的原话（逐字）｜处置——这是维度二的保护清单，
   "写得很好，固定下来"与"整段删掉"同等记录
```

## ③ 循环log 骨架 → `<节号>_循环log.md`

```
一 每轮必读清单（基准排第一；先看成品再看拆解）＋"不进清单"的淘汰名单
二 复发追踪表：编号｜问题｜首次｜复发轮次｜次数｜状态
   —— 次数 ≥3 的强制交子代理逐句扫，不靠自觉
三 核算错误表（单列）：编号｜错在哪｜污染了哪些下游判断｜更正
四 轮次分工（每轮只动一层：语言→语言→节奏→结构→验收→收官）
   —— 层序是路线图不是铁律：可合并、可增删、可提前收束，变阵记进本log
   —— 收官轮＝跨轮择优定英文（不默认取末轮）＋中文改说人话版
   ＋两条贯穿规则：不许大改；每轮改完回扫被改处
五 验收表：硬门槛（逐项，全过才定稿）｜区间指标（由基准实测定标，不许拍数）｜
   停止判据（硬门槛全过／越界≤2且有理由／复发表零新增／对基准比对无新发现）
六 轮次记录：轮｜改了什么｜实测｜方向判定｜新问题｜复发检查｜未解决留给哪轮
七 给自己的话
```
