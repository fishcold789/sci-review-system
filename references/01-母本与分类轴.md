# 01 · 母本与分类轴（L1–L2）

写综述最省力的一步，是**不要自己发明分类**。找一篇本领域公认写得好的综述，看它怎么分；分得合适就沿用或小改，省掉一整轮为了重建分类而做的广泛调研。

---

## 一、什么样的文献能当母本

**一份文献进"母本"的唯一理由是：我们要学它的章节组织方式。不是"它讲了某个方法"。**

讲方法的文献进文献库，讲得好的一篇也只是文献库里的一篇。母本是拿来量的，不是拿来引的。

**一份往往不够，母本按功能分工。** 一个可用的分法：

| 功能位 | 它管什么 | 挑选判据 |
|---|---|---|
| **分类母本** | 这一章分几框、按什么分 | 分类轴清晰，且每一框内部有可辨认的组织线 |
| **起笔与收尾母本** | 从哪起笔、挑战节怎么收 | 对象先行还是方法先行，末章"还缺什么"写得实 |
| **层级母本** | 一类横跨全篇的新东西摆在哪一层 | 有把某类技术放回系统链条而不是孤立成节的处理 |

不必凑满三份。**每多一份母本，必须说清它管哪一件事、不管哪一件事**；说不清就不要收。

## 二、门禁：反例检验（读懂了才有资格改）

照抄一条分类轴之前，先证明你读对了它。**验收动作是找一个反例：**

> 按你说的这条轴，某个条目应该落进 A 框；而母本实际把它放进了 B 框。

找得到反例，说明你摸到了轴的真实判据；找不到，说明你读到的是标题不是轴。

**没有反例 → 只许沿用，不许改。**

反例的常见形态：某方法的观测量与 A 框完全相同，却因为携带了别的信息而被放进 B 框。此时正确的结论不是"作者分错了"，而是"轴不是我以为的那条"。同一个物理量在不同框里扮演不同角色——在一框里是**读数**（读出来的值本身就是答案），在另一框里是**开关**（要的不是这个值，是它翻转时对应的那个位置）。

登记格式（进笔记，不进正文）：

```
我以为的轴：
反例条目：            出现在母本的第几节/第几段
按我的轴它该在：      母本实际把它放在：
所以真实的轴是：
```

## 三、轴不是本体论，是工程史

母本的轴常常**在后面几节自己弱化**——前几框按一个判据分，到某一框改成另一个操作性判据。这不是作者的疏忽，是因为方法都是从实际工程里长出来的，本来就不服从一条统一的分类学。

**不要追求一条一统天下的轴。要理解作者当年为什么这么建。**

跨界方法不必纠结归属，只需交代"我们从哪个视角看它"。母本自己就会出现"某方法本质上也属于 X 框，但我放在 Y 框"的自承——那正是分类是视角不是事实的证据。

## 四、改轴的权限与代价登记

证明读懂之后，可以拿更前沿的调研把轴敲打成更适合自己论文的形状。改的时候登记四件事：

```
改了哪一框：
为什么改（新调研给出了母本当年没有的什么）：
放弃了母本的什么（原轴能解释、新轴解释不了的条目）：
新轴在哪些条目上比原轴更难判：
```

**最保守的改法是"加框不动框"**：原有框原样保留，新问题另开一框。代价是失去"敲打成更贴合"的机会，收益是不必重排全章节序。节序本身也属于母本的一部分——按工程演进顺序排比按逻辑顺序排对读者更友好，因为它复现了这个领域实际的认知过程。若决定不重排，可以在正文里用一句话交代"这里的判据换了"，比靠重排回避更诚实。

## 五、把母本量成数字

分类和节奏都可以照抄，但"照抄节奏"必须落成数字，否则是空话。

**提取管线**（换一篇母本就重跑一遍）：

```
1. pdftotext -bbox-layout <pdf> bbox.xml     # 取每行 xMin/yMin/xMax/yMax 与文字
2. 按行高筛正文（正文行高与图题、参考文献不同，先直方图看一眼）
3. 按 x 分栏（双栏版面用页宽中线）
4. 每页每栏各算 xMin 的众数作为基准缩进
5. xMin > 基准 + 4 pt 的行 = 段首
6. 排序：页 → 栏 → y，按段首切段
7. 连字符断行修复：(\w)-\s+(\w) → \1\2
```

**已知失效模式**：`pdftotext` 提不出行间公式，含公式的段会被切碎。合并办法——把相邻碎片中有一段少于 20 词的合回去，然后看段均是否落回正常区间。

**验证办法**：切出来的段数必须和人工翻一遍的结果对上，对不上先修管线再谈基线。

**词数口径要写下来**（不同正则差 5–8%）。段数、段长比例、句长比例三者不受口径影响，跨文档比较绝对值时才要注意。

量出来至少要有：每节段数、总词数、段均、段长范围、平均句长、从属连词每句、破折号数、括号密度。用 `checks/check_prose_discipline.py 范本.txt --measure` 直接出这张表，存成基线 JSON 供后面验收用。

## 六、母本是有立场的

综述作者会给自己的工作留位置。**先标出母本作者自己的文献出现在哪几段，量篇幅基线时把这几段排除。** 否则你会把作者的偏袒当成"这个主题应有的篇幅"照抄过来。

这是母本的小瑕疵，不影响从它身上提出来的结构；但不标出来就会被继承。

## 七、母本能教而容易被漏掉的几件事

这些不是分类，是写法，值得在精读时专门记下来：

- **节首怎么承接上一节遗留的问题**，而不是"本节讨论 X"
- **哪里六篇挤一个方括号，哪里单独展开一整段**
- **判词有多平淡**——全节最多留一句可记的话
- **只在有史实的地方造桥**：真实的行业转向可以造因果桥；只是维度扩展或逻辑反转就硬切，串联交给章末汇总段。造一座没有证据的桥比不造更糟
- **基础设施讲厚，上层就能讲薄**：前面把一个概念立住，后面的变体一句带过就够
- **并列内容用等长段，递进内容用变长段**
