# 05 · 写作与验收（L6–L8）

---

## 一、L6 逐句读后感：它约束的是表达，不是理解

写之前，把母本对应的那一节**逐句过一遍**，人和模型一起校对，产出一份逐句读后感。

**它的功能不是"读懂母本"**——读懂在 L2–L4 就该完成了。它的功能是：**把文章和人的判断全部拆碎了喂进模型，让它不至于产生偏差，写出来的是人的文章，不是机械化的东西。**

所以读后感回答的不是"作者说了什么"，是**"他为什么这么写"**：每句在干什么、为什么是这个长度、为什么放在这个位置。

配套要产出一份带计量的原文，格式：

```
@@P5  115词 / 3句  句长 [55, 47, 13]
  S1 [55w] ……
  S2 [47w] ……
  S3 [13w] ……
```

有了它，"这段该多长""这句该多长"就不用凭感觉。

**可以直接对照的几条**（从母本量出来的，换母本要重量）：

- **段内句长必有方向**：定义段平；摆前提递减；推向判断递增（最长句即结论）；列条目交替；收尾递减。写完一段把每句词数列出来，**看不出方向就是没设计过**
- **长段后面必跟短段**。短节落差 3–5 倍，长节 2 倍左右（长节每次都掉到很低会碎）
- **落到重点时句子变长**；反过来，一段的最后一句最短，要么它是补充，要么这段没有落点
- **段末句长跟落点复杂度走**：复合判断用长句，单一结论用短句。不是"段末一律长"或"一律短"
- **元话语按节长配给**：短节零元话语；长节可以有，但每一处都要在做具体的事（给地图、防止读者卡在新缩写上、声明绕道、埋前向指针、声明转述来源），**没有一处是"接下来我们将讨论"**
- **诚实标记写进正文**：用的是哪类数据、实验特意做了什么妥协、负面结果照直写。读者因此更信任你没标注的地方

## 二、L7 落笔：两个维度的循环

**先立推进链，再动笔；链没定之前不切段。** 推进链不是段落表，是"这一节的论证怎么往前走"：幕与拍、每一拍做了什么→结果→局限、判词放哪且多重、禁写清单、每条证据的级别。段落只是链最后的切法。

### 维度一｜结构：人机逐段核对，把叙述模型刻出来

- AI 依链出**全量版 A**：能涵盖的都写进去、逻辑从头讲顺，**不管词数——往后每一轮只做减法**
- **人逐段点评**（语域、结构、篇幅分配、段落功能、句式、词语皆可点），AI 按点评出 B、C、D……每版附"相对前稿的改动"表
- 人的原话**逐段逐字存档**——"写得很好，固定下来"与"整段删掉"同等记录。这份实录就是维度二的**保护清单与改动清单**
- **此维度暂停全部计量约束**。实证教训：为让指标达标而写，会拆出结构畸形（按"一句一职"硬写，拆出过十六段的稿子）。指标是维度二的事
- 为什么必须人在环：结构改动全局性、高作废率（16 段→13 段→7 段，每次都是整段级增删）；而"太鸡肋""不吃回头草"这类判断写不成判据——四类不下放的判断密集在这一层。人的逐段裁决还兼任信任检验：机器先证明它真懂了叙述模型，才被允许进入半自主的维度二

### 维度二｜对标：结构冻结后，分层循环收敛

- **唯一基准**：从母本同口径实测出的一份基准文件，每轮改完与它逐段比对；验收区间全部由它的实测定标（不是拍出来的数）
- **分层轮次＝"一轮只动一层"的制度化**：语言 → 语言（复发项交子代理逐句扫）→ 节奏 → 结构（对标补差、词数收敛、书目清零；**分配表在这一轮用**）→ 验收（硬门槛全过才定稿，不过退回）→ 译文（正稿一个字不动）。每轮文件头声明"本轮只动 X 层"，进入条件是上一轮达标
- **两条贯穿硬规则**：不许大改（增删段落、改段序、改段功能、单轮净变超一成，都停下等确认）；**每轮改完回扫被改处**——实测发生过：消除一个复发项的两处修改，各自制造了一处新毛病
- 子代理只做检查与比较，不出稿不改稿；**结论是候选，裁决归人**。越界可申报理由而不硬改：**指标不达标而文字好，优于指标达标而文字坏**

### 循环log：循环的记忆器官

没有 log 的循环只是重复，有 log 的循环才是收敛。固定字段：

- **每轮必读清单**（基准排第一——先看成品再看拆解，反过来会先入为主）＋"不进清单"的淘汰名单（防拿过期文档当依据）
- **复发追踪表**：问题／首次／复发轮次／次数／状态。**同一问题出现三次不是失误，是方法有洞**——强制交子代理逐句扫，不靠自觉
- **核算错误单列**：算错的数让此后所有基于它的判断全错（发生过：连续两版拿错误分母报差值）
- **逐轮记录**：改了什么／实测数值／方向判定／新问题／复发检查／**未解决留给哪轮**——待决跨轮追踪，不静默丢失
- 照实申报，不为凑数硬删

### 分配表与三步除法（维度二·结构轮的工具）

段数 = 目标词数 ÷ 母本段均；句数 = 目标词数 ÷ 母本句均；词数句数按母本节奏形状分到各段（首段短只界定、重心段最长、末段最短只衔接）。**篇幅跟着论证承重走**："这一节是重心"表达为多给几段，不是把一段写长。模板见 `templates/分配表.md`。

## 三、改稿先杀三个病，再守六条

三个病，每个都有可执行判据（语言轮的第一遍扫的就是它们）：

| 病 | 判据 |
|---|---|
| **温吞表达** | 这句话无法被具体事实证伪，就是温吞 |
| **泛泛而谈的确凿** | 删掉"确定性"词（显然、必然、根本），看内容还剩什么 |
| **替读者补课** | 删掉这句，论证链缺不缺环？不缺就删——不解释有科学基础的读者已经知道的事 |

落笔时守的六条：

1. **合并句子只许用冒号、分号、and、but，不许用 which / since / so that。**
   这一条是"压句数成功"与"换一种繁杂"的唯一区别。用从属合并会让句数下降但从属层数上升、块头变大。
2. **条件进括号，引用一并塞入。但每个括号只装一项**，多项条件留在主句用分号分开。
   ⚠️ 括号是把一个功能位塞进另一句话的主要工具。量括号密度时要**排除纯页码引用**——把页码引用算成"条件"，会得出"括号是省字法宝"的错误结论，然后写出一句塞三件事的稿子。
3. **破折号清零。** 每个破折号二选一：并入主句成为并列成分，或删。
4. **长句只许因为列举而长**，不许因为层层解释而长。出现第二层从属即拆句或改并列。
5. **全节一句格言，元话语全删。**
6. **演化靠句序承载，不靠修辞。** 改平语气后若不安排句序，演化线会消失。

## 四、一句一职（功能位）

四项指标全达标仍可能"写得不像"，差的往往不是句子长度，是**一句塞了几件事**。

**一位 = 能独立成句、删掉后论证缺一环的东西。** 母本典型是一句一位；出问题的稿子常见每句 2–3 位。

三条验收：

1. **一句一职**：每句写一个功能标签，写出两个即超载，必须拆
2. **每位挂自己的引文**：一个转引块覆盖超过一条论点即须拆开
3. **括号每处只装一项**

补一条外部基线：**四句以上的段，段内句长标准差 ≥ 8.5**。全节层面此指标不判别。

## 五、验收顺序（不能倒）

```
0  证据核验（读原文、定位、记成立条件与禁止外推）   ← 必须在提纲定稿之前
       ↓  核验会改论点：改错、改方向、出新论点
1  分配表
       ↓
2  逐段落笔，每段写完量三个数：段词数、句均、从属/句
       ↓
3  全节量四项 + 段长序列 + max/min + 功能位数
       ↓
4  判词逐条定位：提纲里的关键判词能否在正文找到
       ↓
5  大词逐条展开：有没有需要读者解码一次的抽象名词
       ↓
6  词数超标时先换 register（条件进括号、去从属），后删论点
       ↓
7  润色
```

**两条不能倒**：0 在 1 之前（核验会改论点）；4、5 在 6 之前（先保住判断和可读性，再压字数）。

一次跑完全部计量：

```bash
python3 checks/check_prose_discipline.py 稿件.md --baseline 母本基线.json
```

## 六、判词不是格言

| | 判断标准 | 处理 |
|---|---|---|
| **格言** | 删掉之后，段落的论证不缺任何一环 | 可删 |
| **判词** | 删掉之后，某条证据失去落点，或某处前后呼应断掉 | **只能改平，不能删** |

改平的做法是去掉隐喻，用普通动词和名词把同一个判断再说一遍。
**改完 register 之后，把提纲里"关键判词"逐条拿到正文中定位。定位不到的，是误伤，不是压缩。**

## 七、大词会压缩含义

把一个判断压进一个抽象名词，句子变短了，但读者要在脑子里展开一次才懂。

落笔时三个自问：这个名词是不是把一整句话压进去了／展开成主谓宾之后是不是就不需要比喻了／展开多出来的字能不能从别处的从句和条件里省回来。

> **可读性优先于字数。省字的正确来源是条件进括号和去从属化，不是压缩含义。**

介绍一篇文献时，**先用中文说清它做了什么、结论是什么，再给英文原句**。原句是证据，不是讲解。

## 八、语言层：两遍，且不改科学含义

**忠实遍**：保住主张、范围、情态动词、否定、归属、数字、单位、条件、引用、图表、公式、章节角色。只改语法、冠词、时态、语序。
**自然遍**：用常见的具体动词和直接主语；减少名词化、堆叠被动、泛泛过渡、密集括号、过多破折号，以及没有可测量依据的夸大词。

**禁用词**：groundbreaking / revolutionary / delve / leverage / pivotal / comprehensive / meticulous / it is worth noting

不改动即输出"无需修改"，不要为了显得做了事而编辑。

**中英回译对照**是语义完整性闸门，不是流畅度评分。逐句逐主张比对：主张集合、观察与解释与因果强度、情态与否定与限制、数字与范围与单位与精度、术语与缩写与归属与引用、实验条件与基线与范围。
数字、否定、因果、责任主体、范围、引用上的**实质漂移 = BLOCK**；轻微漂移交人确认。**一个流畅但丢掉了限制条件的译文仍然不及格。**

## 九、一轮只动一层

科学事实、结构、语言、格式不能混在一轮里无记录修改。**每版必须写出"相对前稿的改动"表并注明所属层。**

版本号三位：

| 位 | 含义 |
|---|---|
| 整数位 | 整轮重写（段数变了、段落功能重新分配、语气切换） |
| `.1 .2` | 同一结构基线上的指标校正，只动形式层 |
| `.5` | 同一结构基线上的内容补写与事实更正，段落序列不变 |

日期后缀只加在快照上（核验、对照表、审计），版本号只加在会被取代的文档上。两者不混用。
