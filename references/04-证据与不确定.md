# 04 · 证据与不确定（贯穿全程）

证据卡存在的理由不是记账，是**论文太多记不住**。它记的不是这篇论文讲了什么，是**这篇对我们整篇贡献了哪个陈述、哪个判断**。

---

## 一、证据卡：五格，一条主张一张

```
编号：
主张：            （它支撑我们正文里的哪一句）
原文定位：        页码 / 图号 / 表号 / 行  ← 没有定位就不是 A 级
级别：            A / B / C / 判断
成立条件：        原文自己给的
禁止外推：        我们判断的
```

**成立条件与禁止外推是两格，不能合并**：前者是原文给的，后者是我们加的。合并之后无法区分"作者说的"和"我们推的"。

### 四级

| 级别 | 含义 | 允许承载什么 |
|---|---|---|
| **A** | 已获全文，定位到具体页/图/表 | 任何结论，包括定量结论 |
| **B** | 文献在手但未定位到具体位置 | 定性判断 |
| **C** | 仅通过二手转述（他人综述、摘要、译本）获得 | **只能用于定位文献，不得承载任何定量结论** |
| **判断** | 我方推断 | 见下方删除测试 |

**删除测试**：判断级不得作段落论点句或收束句，除非同段有 A 级证据直接支撑。
理由：段落承重一旦落在我方推断上，被质疑时整段塌掉。

## 二、不确定不是免责声明，是一种状态

| 状态 | 含义 | **允许的动作** |
|---|---|---|
| `已核验` | 可靠来源＋精确锚点支持这句话 | 写成有边界的事实 |
| `有支撑` | 证据支持，但范围、强度或条件受限 | 用弱式措辞，保留限制 |
| `不确定` | 来源、条件、解释或推理不完整 | **不得写成定论** |
| `需人工核验` | 需要专家判断、存在冲突、或高风险解释 | **停住这条主张**，建检查点 |

**强制升级到"需人工核验"的触发器**（命中任意一条即升级）：

来源缺失或只有摘要 · 数字缺页码/图表号/单位/条件 · 两篇文献结论冲突 · 需要推断物理机制或因果 · 最新结果超出可核验范围 · 在不兼容条件下比较方法 · 术语/公式/算法/设置含义不清 · 这条主张会改变一个高风险结论。

## 三、人工问题包（不许只说"请确认一下"）

```
问题：
需要核验的原文或判断：
已有证据：
冲突 / 不确定在哪：
模型可以确定的部分：
模型不能自行判断的部分：
建议请教对象：
核验结果：
核验日期：
影响的主张、章节和产物：
恢复时使用的基线版本：
```

人的一次决定只解锁列出来的那几条主张和它们的下游，**不默默地把无关断言一起放行**。

## 四、断言强度不得超出原文

| 原文说的 | 不许写成 |
|---|---|
| 需求（`is required`） | 成就（`delivers` / `achieves`） |
| 他人立场／某文献认为 | 事实 |
| `within 10%` | `±10%` |
| `可能 / 提示 / 表明 / 支持` | `证明 / 必然 / 建立了因果关系` |
| 转引（C 级） | 定量结论 |
| 图像更清晰 / 信噪比更高 | 尺寸更准 |

综述只承担分类与接口职责，**不能替代原始实验论文承担性能数字**。

术语、公式、算法名、实验设置含义不清时，建不确定记录并交人，**不要静悄悄选一个看起来合理的同义词**。

## 五、禁止等价表（通用三条 ＋ 本项目必填）

通用、任何理工科都成立：

```
关联            ≠ 因果
基准增益        ≠ 域外鲁棒
综述的转述      ≠ 原始实验结果
统计上的变化    ≠ 工程上有意义的变化
```

**本项目还必须自己列 3–5 条**，写在项目自己的笔记里，不写进本技能。形式是"看起来等价其实不等价"，典型模板：

```
某个感官/中间指标  ≠  任务真正要的那个指标
```

**没有这张表 → 跨文献比数字这个动作阻断。** 因为通用三条挡不住本领域最容易犯的那一类混同。

## 六、跨文献比数字前的可比性核对

比之前逐项记录：研究对象、方法与处理、输入与输出定义、测量条件、指标定义与单位、样本或数据集、协议、数据划分、真值来源、不确定度、混杂因素、可能的数据泄漏。

**缺条件产生"不确定"，不产生"默认一致"。** 缺失信息与阴性结果是两件事，不能混。

输出：对比表 ＋ 可比性裁决 ＋ 缺失条件清单 ＋ 指标与真值说明 ＋ 一个有边界的措辞建议。

## 七、缺口登记：门禁文档

证据不够但必须写的地方，登记成表：

| 编号 | 主张 | 缺什么 | **当前允许的写法** | 到位后可改写为 | 删除测试 | 状态 |
|---|---|---|---|---|---|---|

**门禁：证据缺口登记未清零，不得进入润色。**
理由是润色会把弱式句改得更好听而不是改平，顺手抹掉证据级别标记。

## 八、正文与台账必须能对账

台账再完整也证明不了正文——除非两者之间有锚点。最低要求：

```
正文某句 → 主张编号 → 证据编号 → 来源页/图/表
```

双向查：每一句高风险陈述都指得到主张与证据；每一条高风险证据都说得出它用在哪，或为什么至今未用。

跑一遍：

```bash
python3 checks/check_emptiness.py 证据包.json      # 结构完整但内容空洞会被拦下
python3 checks/check_emptiness.py 稿件.md --text   # 散文按段落判
```

## 九、图件也要溯源

```
主张 → 图/表 → 来源文献/页/子图 → 裁剪与哈希 → 版权状态 → 首次引用位置
```

没有可追溯来源的图不是可复用资产。截图或改画的子图不得称为原创。
科学有用性、引用映射、版权许可是三件独立的检查，不要合成一条。
