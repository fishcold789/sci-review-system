# Journal adaptation and delivery

Apply this reference only when venue state is `candidate` or `confirmed`; use
`optional-journal-and-package-policy.md` for the authoritative state and
packaging rules. A `not_selected` venue is a valid skip, not a missing PASS.

Treat journal scope, author guidelines, indexing, APC, review time, and
submission fields as dynamic facts. Verify them from official sources and
record access date and URL. Do not infer author, funder, ethics, conflict,
AI-use, or copyright declarations.

Journal adaptation changes structure, terminology, length, figure/table format,
and reference style only after the target profile is selected. It must not add
scientific claims or override evidence gates.

Submission work follows the user's manifest, template, or explicit package
instruction. It may produce a checklist, missing-materials list, risk list,
package manifest, and human confirmation list, but it does not impose a
universal bundle. The user performs login, payment, legal acceptance, and final
Submit.
