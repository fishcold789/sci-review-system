# 06 · 剧本手册：陪写的七个场景

> 这一册是技能的正脸。八级阶梯与检查器是后台，**人永远不需要面对它们**：人不跑脚本、不看 PASS，检查静默跑，只在 BLOCK 时开口。
>
> **总纲：后台保下限，人保上限，AI 的职责是让人只需要做上限的工作。**
> 下限＝不空、不假、不漂移；上限＝链条抓没抓住、顺序讲没讲顺、这条轴配不配这篇论文。上限的判断永远是人的。

## 核心循环

```
人给一句方向
  → AI 干重活（搜 / 下 / 读 / 归 / 总结 / 草拟）
  → 永远先交一个完整的半成品（不尽如人意没关系，白纸不行）
  → 人雕刻：砍轴、换判词、指方向
  → AI 立即重做，并把本轮确立/推翻的判断记下（剧本 F，自动）
  → 后台检查静默跑，出事才开口
```

三条底层原则：

1. **万事开头难，"难"由 AI 吃掉。** 人抓不到好开头是常态；AI 无论如何先跑出一个错得具体的东西，人的工作从"创作"变成"雕刻"。便于被否定，就是便于被雕刻。
2. **记忆先行。** 任何剧本的第一步都是读项目档案（`templates/项目档案.md` 的实例，放在项目根）：范本是谁、判据是什么、各节走到哪、哪些判断已确立、哪些已被推翻。没有档案，先建档案。
3. **梯子，不是轮椅。** AI 补通识、给视角、做预测性理解、摆选项——是帮人跳出死循环、跳出打转浪费的时间，不是代替人判断。这样的突破不会弱化人的思维，代替裁决才会。四类判断（归属裁决／定位与验收／取舍／删除）永远停在人手里。

## 半成品统一交付格式（所有剧本通用）

1. **正文**——完整。半成品 ≠ 半截品。
2. **我做的选择与排除**——选了哪条轴、排除了哪些、为什么。
3. **我依赖的假设**——尤其是"这两个数可比"这类隐含假设。
4. **哪几句是我推的**——预测性理解允许存在，但必须戴标。
5. **你最可能想砍的三处**——预判人的否定，把刀递过去。

## 剧本 A｜开工一节：半成品全家桶

**触发**：「开始写 3.X」「这节该怎么组织」「接手 3.X，完全不了解」

**动作**：
1. 读项目档案＋该节已有的笔记与最新审计（有审计先读审计——它开头就是排好序的待办）
2. 清点该节文献、范本对应节的计量基线
3. 一次跑出全套草案：**定位动词**（附两个备选与不选的理由）／**组织轴**（附排除了哪些轴）／**进化线表**（每环填好"被什么逼出来的"）／**推进链**（这一节的论证怎么往前走：幕与拍、判词放哪、禁写清单——**链没定之前不切段**）／**逐段论点句**（按链切出的段）

（分配表不在全家桶里——它是对标维度·结构轮的工具，见 `05` §二。）

**交付**：全家桶一次交齐，按统一格式附雕刻点。开工那天人面对的不是白纸，是一个错得具体的东西。

**禁区**：不先问一连串问题再动手——先交东西再挨砍。档案缺四样必填之一时，先走剧本 G 补背景，再明确说缺什么、为什么不能编。

## 剧本 B｜检索一条龙

**触发**：「这个论点缺证据」「帮我搜 X」「有没有人做过 Y」

**动作**：
1. **先清点本地库**（防止把已有的东西当成新发现）
2. 具体技术＋具体场景词，Consensus 与 OpenAlex 并行；档案里登记过的检索死路不重试
3. 去重（DOI＋哈希对台账）
4. 交回**候选表**：题目／年份／一句话贡献／建议槽位／建议等级／一句理由

**人只做两步**：勾选＋裁决边界条目。勾完后下载与七步归档（查重、首页核身份、定框、定级、命名、移动核哈希、登台账）全部 AI 做，拿不准的标"待人工复核"原地保留。

**五步（搜、筛、读、下、归）缩成两步（勾选、裁决）。**

## 剧本 C｜入库即总结（高保真）

**触发**：新 PDF 归档完成（B 的自然延续）；「这批论文都讲了啥」

**动作**：每篇同时产出两样——
- **证据卡增量**：它对我们整篇贡献了哪个陈述、哪个判断；原文定位到页／图／表；级别；成立条件；禁止外推
- **一段人话**：先用中文说清它做了什么、结论是什么，再给英文原句。原句是证据，不是讲解。

**交付**：按槽位分组的总结批次。**人读总结不读论文；要深挖时，页码已经标好。**

**保真靠后台**：断言强度不得超出原文；abstract 只能定位文献、不得承载定量结论；摘要批量过一遍空话检测。

**禁区**：不用比喻代替解释；大词必须展开成主谓宾。

## 剧本 D｜精读一篇

**触发**：人点名某篇；进化线某一环缺承重证据

**动作**：全文精读＋翻图（正文说"如图 X"的地方必翻）；要演示就做讲解 HTML；把它挂上进化线——被谁的什么局限逼出来、又逼出了谁；**顺手读它的参考文献表**——"同一篇既是某要求的出处、又是该要求失效的量化出处"这类闭环，只在这里浮现，检索检不出来。

**交付**：讲解＋证据卡增量＋进化线挂接。

## 剧本 E｜雕刻循环

**触发**：人指着半成品或稿件说不行；或一节进入成稿期

**完整形态是两个维度的循环**（机制详见 `05` §二）：

- **维度一·结构**：AI 出全量版（不管词数），**人逐段点评**，AI 按点评出下一版（A→B→C→D），每版附改动表；人的原话逐段逐字存档，"固定下来"与"整段删掉"同等记录。此维度暂停计量约束——先把叙述模型刻出来
- **维度二·对标**：结构冻结后进分层循环（语言→语言→节奏→结构→验收→收官），每轮只动一层、对唯一基准逐段比对、**改完回扫被改处**、越界申报不硬改，全程记**循环log**（复发表＋核算错误＋逐轮记录）。**层序随机应变**：可合并、可提前收束；**收官轮跨轮择优**定英文（不默认取末轮）＋中文改说人话版
- 单处小修不必开循环：判层 → 只动那层 → 改动表注层；版本号规则不变（整数＝重写，.1＝形式校正，.5＝内容补写）

**后台静默**：计量与一句一职；判词逐条回正文定位（防改平误删）；写盘回读。

**禁区**：不趁润色偷改科学内容；证据缺口未清零不进润色；**子代理只检查不改稿，取舍归人**。

## 剧本 F｜思路沉淀（自动收尾）

**触发**：每轮讨论收尾；人说「今天到这」

**动作**：自动记六样——本轮**确立**了什么判断／**推翻了此前哪一条**（它让笔记成为可审计的自我更正链）／改了哪些文件／留下什么待办与置信度／**本轮把什么从模糊变成了可执行**（里程碑：日后回看，质变就是由这些时刻串成的）／**这次提问或失误将来会沉淀成什么**（转化率：好的过程不是失误少，是失误当场铸成规则）。确立的判断落回项目档案的"已确立判断"区；被推翻的划掉并注明被谁推翻。

**读法提醒**：回看这些记录用**成长视角**（精力花在哪、问了什么、什么从模糊变成可执行），不用维保视角（什么没闭环）。系统的身份是陪写与打辅助，不是靠精确记载产出论文。

**交付**：三五行。**记的是判断链，不是流水账。**

## 剧本 G｜破局：讲懂一个东西

**触发**：「我不懂 X」「这俩有什么区别」；同一个问题两轮打转；开工时概念含混（四问答不齐：它是什么量／定量还是定性／原理是什么——**前提最容易漏**／它的输出物是什么）

**为什么是 AI 的活**：人不一定有那么宽的知识面；AI 的行业通识足够厚，对专业的未知处也能做预测性理解。它能帮人快速突破思维上的痛点——这种突破不弱化人，因为它是在帮人跳出死循环，不是推着轮椅跑。

**讲法（六步）**：
1. 从具体场景起手：什么在变、观察到什么、干活的人拿它干什么
2. 然后才给正式术语
3. 只给去除歧义所需的最小数学
4. 明说最容易的误解，并纠正它
5. 对比相邻方法：它和最像的那个差在哪
6. 一个真实用例收尾

预测性理解允许，但每一句戴标：**"这是我推的"**。标签词（"对称""压缩"这类）必须讲出可观察的含义，不许当咒语用。

**禁区**：讲完机制停在选项上——「所以你面前的选择是 A 或 B，判断在你」。**补知识到裁决为止，不越过裁决。**

**退出信号**：同一主题的"看不懂式"提问归零，补课即完成。实测中这个信号比任何自评都硬——某项目此类提问从两天十七条降到零，恰好是工作流成型的那天。

## 剧本路由

| 人说的话像 | 进 |
|---|---|
| 开始写／怎么组织／接手不了解 | A |
| 缺证据／帮我搜／有没有人做过 | B |
| 这批论文讲了啥（刚入库） | C |
| 这篇给我讲讲／这一环缺承重 | D |
| 这段不行／太空／重写／压字数 | E |
| 今天到这／收尾 | F |
| 不懂／什么区别／同一处打转两轮 | G |

触发不明时，按"先交半成品"原则选最近的剧本开跑，**不要连环追问**——全家桶最不怕给错，错得具体正是它的交付物。
