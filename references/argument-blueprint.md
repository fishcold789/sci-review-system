# Argument blueprint and paragraph contract

Before writing prose, bind each section or paragraph to an argument contract:

```yaml
unit_id: U-001
upstream_question: "..."
new_information: "..."
claims: [C-001]
evidence: [E-001]
assumptions: ["..."]
cost_or_burden: "..."
output_to_next_unit: "..."
must_not_claim: ["...", "..."]
figure_or_table_need: "..."
```

Use the active project profile's mechanism or information chain when one is
configured; otherwise derive a field-neutral chain from the review protocol and
evidence ledger. A paragraph should introduce a problem, add a specific piece
of information, state the evidence and boundary, and hand a well-defined output
to the next paragraph or work unit.

Distributed agents may produce paragraph packages, but the main agent must
rebuild the full section so terminology, causal links, citation strength, and
transitions are consistent.
