# Citation and reference integrity

Maintain separate but linked assets:

```text
bibliography master -> evidence citation library -> manuscript citation view -> journal format view
```

Check DOI/title/author/year duplicates; every in-text citation exists in the
reference list; every included reference is used or has an explicit reason;
source page/figure/table anchors are valid; the citation supports the sentence;
a review is not used to support an original performance number; and citation
scope does not exceed the evidence.

Reference formatting is a delivery adapter. Do not let formatting changes alter
source identity, claim mapping, or evidence strength.
